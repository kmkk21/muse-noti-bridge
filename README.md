# Muse 알림 브릿지 (MuseNotiBridge)

Meta **Muse AI** 에이전트와 안드로이드 스마트폰을 연결할 때 발생하는 **"핸드폰 연결 해제 / 오프라인"** 문제와 **토큰 과다 소모** 문제를 해결하기 위해 만든 전용 안드로이드 브릿지 앱입니다.

## 핵심 기능

1. **광고 푸시 알림 로컬 즉시 삭제 (토큰 0원)**
   - `(광고)`, `특가`, `쿠폰`, `할인`, `이벤트` 등 광고 키워드가 포함된 푸시 알림을 폰에서 **0.1초 만에 자동 삭제**하고 Muse에는 전송하지 않습니다.
2. **토큰 절약형 필터링 · 중복 제거 · 본문 압축**
   - `인증번호`, `OTP`, `로그인 알림` 등 민감·노이즈 알림은 자동 제외합니다.
   - 60초 이내 동일 알림 중복 제거 + 본문 최대 글자 수 제한(기본 160자)으로 토큰 폭증을 방지합니다.
   - 로컬에서 **`가계부/결제` · `일정/예약` · `일반/중요`**로 사전 분류해 Muse의 분석 정확도를 높입니다.
3. **오프라인 내성 배치 전송 (Push 방식)**
   - Muse가 꺼진 폰에 접속(Pull)하려다 실패하는 대신, 앱이 **WorkManager**로 알림을 모아두었다가 설정한 주기(기본 2시간)마다 한 번에 묶어 전송합니다.
   - 비행기 모드나 오프라인 상태였다가 인터넷이 복구되면 밀린 알림을 자동으로 재전송합니다.
   - `해외결제`, `부정사용`, `연체` 같은 긴급 키워드는 배치를 기다리지 않고 즉시 전송합니다.
4. **2가지 간편 연동 채널**
   - **Muse Mail / 이메일 (SMTP — 추천)**: Gmail/네이버/Outlook 앱 비밀번호로 내 Muse 에이전트 주소(`xxx@muse.ai`) 또는 Muse가 읽는 메일함으로 바로 전송
   - **Webhook (HTTP POST JSON)**: Muse Custom Connector, n8n, Make, Google Apps Script 등과 바로 연동

## 설치 및 초기 설정 (3분 완료)

1. [Releases](https://github.com/kmkk21/muse-noti-bridge/releases)에서 최신 `MuseNotiBridge-v1.0.1-release.apk`를 안드로이드 폰에 다운로드해 설치합니다.
   - 갤럭시에서 설치가 막히면 `설정 → 보안 및 개인정보 보호 → 보안 위험 자동 차단`을 잠시 끄고 설치한 뒤 다시 켜세요.
   - 설치 후 `알림 접근 권한`이 회색으로 비활성화된 경우(안드로이드 13+): `설정 → 앱 → Muse 알림 브릿지 → 우측 상단 ⋮ → 제한된 설정 허용`을 한 번 눌러주면 열립니다.
2. 앱을 열고 **대시보드**의 3가지 체크리스트를 순서대로 탭합니다:
   - **알림 접근 권한** 허용
   - **배터리 절전 예외** 허용 (갤럭시 One UI 절전에서도 연결 유지)
   - **Muse 연동** 탭에서 **Muse Mail(이메일)** 또는 **Webhook** 설정 후 **테스트 전송** 확인
3. 기존 Muse 앱에서 *"핸드폰 알림을 직접 읽던 예약 작업"*을 중지해 두면 오프라인 오류와 백엔드 과부하가 완전히 사라집니다.
